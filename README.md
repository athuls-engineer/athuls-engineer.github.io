# Athul S — Personal Engineering Portfolio Website

The open-source codebase for my personal engineering portfolio website showcasing hardware, embedded firmware, IoT, and Edge AI projects.

🌐 **Live Website**: [https://athuls-engineer.github.io](https://athuls-engineer.github.io)

---

## 🛠️ Tech Stack & Architecture

* **Frontend**: HTML5, Vanilla JavaScript (ES6+), Modern CSS
* **Styling**: Tailwind CSS
* **Icons**: Lucide Icons
* **Zero Build Steps**: Pure client-side delivery with zero framework dependencies, hosted on GitHub Pages.

---

## ⚡ Key Sections

* **Engineering Projects**: Interactive filters and deep-dive modals for IoT/telematics, systems, and hardware projects.
* **Competencies & Skills**: Detailed skill matrix covering microcontrollers, communication protocols, EDA tools, and software languages.
* **Experience**: Summary of industrial internships at NeST Technologies and KSEB.
* **Direct Contact**: Interactive contact section with direct copyable contact pills and mailto links.
