# 🌟 Athul S — Professional Engineering Portfolio Website

A futuristic, high-performance, colorful portfolio website showcasing all projects, internships, skillsets, and credentials from **Athul S's** resume.

Built with **HTML5, Tailwind CSS, Custom Modern CSS, Lucide Icons, and Vanilla JavaScript** — zero framework dependencies, zero build steps, and ready to host **100% FREE forever**.

---

## ⚡ Live Features

1. **Cyber-Nebula Visual Theme**: Deep glassmorphism cards with glowing neon gradients (Cyan, Violet, Emerald, Amber).
2. **Dynamic Hero Section**: Interactive typewriter headline, quick stats counters, live status indicator, and copyable contact pills.
3. **Interactive Project Filter**: Filter core engineering projects across IoT/Embedded, FPGA/Verilog, and RF/Antenna.
4. **Project Deep-Dive Modals**: Detailed architectural breakdowns, system flows, and technical deliverables for each project.
5. **Interactive Skill Matrix**: Filterable competency matrix with visual proficiency meters across hardware, software, EDA tools, and protocols.
6. **Industrial Experience Timeline**: Alternating glowing timeline highlighting NeST Technologies and KSEB internships.
7. **Interactive Contact Hub & Mailto Dispatcher**: Form that automatically composes and launches direct emails to `athuls2580@gmail.com`, with one-click copy buttons for phone and email.
8. **Interactive Printable Resume Modal**: Built-in resume viewer with clean print-to-PDF styles.

## 🚀 How to Publish Freely (Zero Cost Forever)

You can host this website completely for free without paying a single dollar. Pick any of the following 3 easiest options:

### Option 1: GitHub Pages (Recommended & Permanent Free URL)

1. Go to [github.com/new](https://github.com/new) and create a repository named `athul-portfolio` (or `athuls-engineer.github.io` for your main root domain).
2. Upload all the files inside this directory (`index.html`, `style.css`, `app.js`, `README.md`).
3. Go to **Settings** -> **Pages** (in the left sidebar).
4. Under **Branch**, select `main` (or `master`) and click **Save**.
5. Within 60 seconds, your site will be live at:
   `https://athuls-engineer.github.io/athul-portfolio/` (or `https://athuls-engineer.github.io`)

---

### Option 2: Netlify Drop (1-Click Drag & Drop — No Coding Needed)

1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the entire `athul-portfolio` folder into the upload box.
3. Netlify will instantly give you a free live URL (e.g., `https://athul-s-portfolio.netlify.app`).
4. You can customize the subdomain name anytime under **Site Settings -> Change Site Name**.

---

### Option 3: Vercel

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New Project** -> Import your `athul-portfolio` repository.
3. Click **Deploy**.
4. Your site will be published on Vercel's global edge network instantly with a free `.vercel.app` domain.

## 💻 Local Testing & Offline Use

You don't need any server to run this locally! Simply double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.

Alternatively, if you have Python installed, you can preview locally via:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
